## Findings and implemented repairs

1. Failed initial MongoDB connections reset a promise but never scheduled a retry. Added a shared connection lifecycle with bounded exponential backoff and jitter. Established connections remain under the MongoDB driver's recovery logic. Shutdown cancels retries. Diagnostics emit categories instead of raw connection errors; pool sizing remains unchanged.
2. Reports retained only summaries. Added versioned JSON snapshots of completed results, including methodology/version and original multilingual evidence. Snapshots are excluded from ordinary queries, limited to 2 MiB, and reopened through owner-scoped `GET /reports/:id/result` without crawling, writing reports or reserving quota. Oversized results retain an explicitly identified summary. Historical summaries remain readable and are never presented as complete reports.
3. Logout only cleared a cookie. Added an additive account session version, incremented on logout to revoke all JWT sessions; password/key rotation still revokes credentials. The browser waits for logout success and reports network failure. Existing sessions require a new login after this change. API-key rotation now checks whether its conditional update succeeded.
4. Foreign or invalid project scans could consume quota before ownership validation. Ownership is now checked before reservation. Cross-origin login and other explicit unsafe requests are rejected even without an existing cookie. Duplicate registration conflicts return 409. Account deletion rechecks running work after acquiring its local deletion guard.
5. The page validator accepted PARTIAL_PAGE while the orchestrator rejected it. Short analyzable pages now receive observed-HTML scores with a limited-content flag. Challenge, error and empty pages still stop. Disabled browser fallback and HTTP errors retain their original diagnostics rather than replacing them with a browser-unavailable failure.
6. Unavailable link/asset/robots/sitemap samples could count as passes, and the monitor declared 12 checks while implementing 11. Pass/unknown counts now use explicit tri-state results. Unavailable or inapplicable technical metrics are excluded from scoring. Engine-profile prose now cites actual answer/table/schema observations and marks the profiles as illustrative heuristics, replacing blanket FAQ/HowTo/table advice.
7. Mobile CSS hid the primary navigation. Navigation now wraps on small screens; the mobile header no longer obscures report content while scrolling. Existing design and features are retained.
8. PDF export depended on a remote rasterization bundle. Export now opens the browser's local Print / Save PDF dialog, expands report details for printing, applies A4 pagination, preserves selectable RTL text and restores collapsed states afterwards. It no longer needs that external PDF library.
9. Extended English, Urdu, Pashto and Arabic copy for export, saved reports, action controls, crawler policy states, technical coverage and evidence-backed profiles. Switching languages rerenders cached state without additional requests or quota.
10. Added real database, browser and recovery acceptance scripts. CI now runs an isolated MongoDB replica set and Chromium desktop/mobile/PDF checks in addition to existing regressions and the dependency audit. Generated databases and artifacts are excluded from Git and Docker build context.
